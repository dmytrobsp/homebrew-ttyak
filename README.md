# Homebrew tap for ttyak

[ttyak](https://github.com/dmytrobsp/ttyak) is a native Slack client for the terminal.

```sh
brew install dmytrobsp/ttyak/ttyak
```

macOS (Apple Silicon and Intel) and Linux (x86_64 and arm64). The formula is updated by ttyak's release workflow on
every release; please report problems at https://github.com/dmytrobsp/ttyak/issues.
